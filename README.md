# AI Sport Coach v4

เว็บไซต์ต้นแบบ AI Sport Coach สำหรับโครงงานนวัตกรรม ใช้ HTML, CSS, JavaScript และ MediaPipe Pose Landmarker สามารถนำไปเผยแพร่ผ่าน GitHub Pages ได้

## สิ่งที่เพิ่ม/ปรับปรุงใน v4

- คงโหมดฝึกท่าเดียวไว้ และเพิ่มโหมดโปรแกรมฝึกเป็นรอบ
- มีโปรแกรมตั้งต้น Beginner Starter, Low Impact และ Full Body และผู้ใช้สามารถเลือก/เอาท่าออก/เพิ่มท่า/เลื่อนลำดับได้
- โปรแกรมแบบรอบกำหนด 20 วินาทีต่อท่า พักระหว่างท่า 10 วินาที นับถอยหลัง 3 วินาทีก่อนเริ่มท่า และพักระหว่างรอบ 15 วินาที
- มีปุ่มพักชั่วคราว ดำเนินต่อ ข้ามท่า และจบการฝึก
- แสดงหน้าต่างแนะนำมุมกล้อง พื้นที่ และอุปกรณ์ก่อนเริ่ม โดยไม่ได้ตรวจจับว่ามีอุปกรณ์จริงหรือไม่
- มีสัญลักษณ์สถานะกล้องขนาดใหญ่ พร้อมสี ไอคอน และข้อความ และเริ่มนับถอยหลังเมื่อกล้องและจุดร่างกายที่จำเป็นพร้อม
- มีหน้าวิธีใช้งานและหน้าคู่มือการทำท่า พร้อมข้อควรระวัง/มุมกล้องสำหรับ 12 ท่า
- สรุปเวลารวม จำนวนครั้งต่อท่า คะแนนท่าโดยประมาณ จุดแข็งและจุดปรับปรุง พร้อมบันทึกประวัติหนึ่งครั้งต่อการฝึก
- ใช้ localStorage เก็บประวัติในเบราว์เซอร์นั้น

## ท่าที่มีในระบบ

Squat, Push-up, Biceps Curl, Jumping Jacks, Jump Squat, Standing Side Crunch, Standing Elbow to Knee, Lunge, Step-ups, Glute Bridge, March in Place และ Standing Side Leg Raise

## วิธีเปิดใช้งาน

1. แตกไฟล์ ZIP
2. อัปโหลด `index.html` ไปยัง repository ของ GitHub
3. ใน GitHub ไปที่ **Settings → Pages** แล้วเลือก branch/folder ที่ต้องการเผยแพร่
4. เปิดเว็บไซต์ผ่าน HTTPS และอนุญาตการใช้กล้อง

โมเดล MediaPipe โหลดจาก CDN จึงต้องใช้อินเทอร์เน็ตในครั้งแรก กล้องบนเบราว์เซอร์โดยทั่วไปต้องใช้ HTTPS หรือ localhost

## ข้อจำกัด

ระบบนี้เป็นต้นแบบเพื่อการศึกษา เกณฑ์นับครั้งและคะแนนเป็น heuristic จาก landmark 2 มิติ ไม่ใช่การรับรองความถูกต้องทางชีวกลศาสตร์หรือการวินิจฉัยทางการแพทย์ ท่าบางประเภท โดยเฉพาะ Step-ups และการตรวจการเคลื่อนไหวในแนวลึก อาจต้องปรับเกณฑ์หลังทดสอบกับผู้ใช้จริง หากมองไม่เห็นข้อต่อสำคัญ ระบบจะแจ้งให้ปรับมุมกล้องแทนการให้คะแนน


## โครงสร้างไฟล์ (เวอร์ชันแยกไฟล์)

- `index.html` — โครงสร้างหน้าเว็บและเนื้อหา
- `styles.css` — สี ธีม ฟอนต์ ระยะห่าง ปุ่ม และ responsive layout
- `app.js` — ระบบตรวจจับท่าทางด้วย MediaPipe, ตัวจับเวลา, การนับ/ประเมินท่า และประวัติการฝึก

### ปรับหน้าตาเว็บไซต์

แก้ไข `styles.css` ได้โดยตรง โดยสีหลักอยู่ในบล็อก `:root` ช่วงต้นไฟล์ เช่น `--bg`, `--panel`, `--green`, `--text` และ `--muted` ส่วนฟอนต์หลักกำหนดในกฎ `body`

ควรวาง `index.html`, `styles.css` และ `app.js` ไว้ในโฟลเดอร์เดียวกัน และอัปโหลดไฟล์ทั้งหมดไปยัง GitHub Pages พร้อมกัน
